## Debrief

- **What worked:** It creates the 3-column clickable dashboard as request via prompt, including such as a button for 'Process Transcript' to allow users to click and trigger a loading state, formatting like dark-mode/ maximum width, etc._____
- **What broke / felt like a toy:** The AI summary usually misses the actual signal. The CSV or file export crashes or take long time. The format like the blue navigation bar is too bright to user._____
- **What I'd change next pass:** Keep the things user mentions s/he likes, such as the dark-mode. Change the things user has comments: blue bar is too bright so may change to darker color; user expects to select date range while having Last 90 Days as the default. Upload a screencap as an example to show expected output then prompt with it to fix._____
