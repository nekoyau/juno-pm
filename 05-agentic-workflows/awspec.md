## Goal

Create and update P0 escalations into a daily prioritised top-3 business most-wanted list, with a strategic-rationale citation per item.

**Primary actor:** Agent + Human-in-the-loop

## Trigger

New message in Slack channel #project_smes and new Zoom meeting tagged P0 AND mentioned by more than 3 persons in a calendar week.

## Steps & tools

**Pattern:** ReAct (single-agent reason-act-observe loop)

| Step | Action | Tool / model | Guardrail |
|---|---|---|---|
| 1 | Read the Slack threads and Zoom meetings transcripts + retrieve customer ID/name and post date. | slack.read_thread(id), read-only | Agent can READ Zoom meeting summary + Strategy KB. Agent can WRITE to Slack #project_smes and #pm-review. Agent CANNOT edit any Slack threads, edit the auto-post threads after creation, or post outside Slack channels {#project_smes and #pm-review}. |
| 2 | Long Context read through the Strategy One-Pager (M3 KB), top-K = 10. | usecase.retrieve(query, k=6), read-only |  |
| 3 | Score most mentioned vs strategic pillars; emit P0-P3 with rationale. | strategy.lookup_arr(strategy_id), read-only |  |
| 4 | Draft summary card (transcript quote + strategic citation). | slack.post(channel), write, restricted to #project_smes and #pm-review |  |
| 5 | Post to Slack #project_smes OR route to PM review based on confidence threshold. | _ |  |

**Schemas**

- usecase.retrieve → {chunks:[{text,source,pillar,score}]}.
- strategy.lookup_arr → {strategy_id, strategy_name, priority_num}.


**Memory (in or out of scope)**

- **Episodic:** In-scope, tool results, retrieved chunks, intermediate scores. Lifetime: end of run.
- **Semantic:** In-scope, strategic taxonomy + Juno system prompt + PM preferences. 
Lifetime: indefinite, refreshed weekly, last for 1.5 months. 
Out of scope, do NOT include cost or financial information.
- **Working:** In-scope against the strategic KB, current thread within the specific time period, customer name, retrieved KB chunks, current confidence score. Held in working context only.
- **External:** Slack thread API (read), Zoom meeting API (read), Strategy KB (read), (read), #project_smes channel (write), #pm-review channel (write).

## Human-in-the-loop

PM reviews any P0 with confidence < 70% before posting. Daily 10:00am HKT: PM has a 30-min review window before the agent auto-posts to Slack channel #project_smes.

## Success & failure

- **Done when:** - Success: top-3 business most-wanted list posted to #project_smes.
- Failure: > 2 tool errors in a run → log + abort.
- Escalation: confidence < 70% on any P0 → hand to PM.
- Timeout: 90s wall clock → abort with partial output.
- **Fails safe when:** Agent can READ Zoom meeting summary + Strategy KB. Agent can WRITE to Slack #project_smes and #pm-review. Agent CANNOT edit any Slack threads, edit the auto-post threads after creation, or post outside Slack channels {#project_smes and #pm-review}.
